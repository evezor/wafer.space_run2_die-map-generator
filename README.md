## Setup & Run

### CPython

#### Prerequisites

You need **Python 3.10 or newer** installed on your computer.

- **Windows**: Download from [https://www.python.org/downloads](https://www.python.org/downloads). During installation, make sure to check the box that says **"Add Python to PATH"**.
- **Mac**: Download from [https://www.python.org/downloads](https://www.python.org/downloads), or install with Homebrew: `brew install python`.
- **Linux**: Python is usually pre-installed. Check with `python3 --version`. If it's missing or too old, install with your package manager (e.g. `sudo apt install python3`).

#### Running the Project

1. **Extract** this ZIP file to a folder on your computer.
2. **Open a terminal** in that folder:
   - **Windows**: Open the folder in File Explorer, click the address bar, type `cmd`, and press Enter.
   - **Mac**: Right-click the folder in Finder and choose "Open Terminal Here" (or open Terminal and type `cd ` then drag the folder in).
   - **Linux**: Right-click in the folder and choose "Open Terminal".
3. **Install dependencies** by running:
   ```bash
   pip install -r requirements.txt
   ```
   If that doesn't work, try `pip3 install -r requirements.txt` instead.
4. **Start the project**:
   ```bash
   python main.py
   ```
   If that doesn't work, try `python3 main.py` instead.
5. **Open your browser** and go to [http://localhost:8000](http://localhost:8000).

#### Stopping the Project

- Go back to the terminal and press `Ctrl+C` to stop it.
